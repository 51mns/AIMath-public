# Licensing decision

AIMath Public should have an explicit licence before broad third-party reuse.

## Recommended split

- **Code:** Apache License 2.0  
  Reason: permissive reuse plus an explicit patent licence and clear contribution terms.

- **Original mathematical prose, diagrams, and project-authored documentation:** Creative Commons Attribution 4.0 International (CC BY 4.0).

- **Third-party material:** keep its original licence/citation, or do not redistribute it if reuse rights are unclear.

## Current bootstrap status

No licence is granted by this bootstrap file itself. The repository owner should explicitly add the chosen licence text(s) before announcing the repository as generally reusable.

This is intentionally a human/legal ownership decision rather than an automated export step.
