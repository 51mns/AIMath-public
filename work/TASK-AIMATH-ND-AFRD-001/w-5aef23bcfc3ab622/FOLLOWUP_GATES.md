# AFRD follow-up gate sequence

## G0 — contract acceptance

Input: this E0 package.

Pass only if the information firewall, N-only rule, H0-H5 split contract, freeze point, resource accounting, baseline classes, signal gate, post-signal audit order, and promotion rule are internally consistent and independently reviewable.

## G1 — blind representation discovery

A **new** discovery worker that has not inspected evaluator baseline detail or another discovery lane's representation receives only the allowed discovery packet. It freezes `X(N)` and all readouts before any hidden result is revealed.

Output: frozen candidate package or `LEAKAGE_ABORT` / `NO_REUSABLE_PROGRESS`.

## G2 — hidden utility evaluation

Evaluator runs H0-H5 exactly once per frozen candidate version. No candidate tuning after hidden exposure. Report localisation curves, factor success at all resource caps, raw-N matched controls, best classical/representation baseline, and the exact paired gate.

Output: `NO_SIGNAL` or `HELD_OUT_SIGNAL`.

## G3 — independent falsification

Required only after `HELD_OUT_SIGNAL`. Re-run generator, temporal, arithmetic, reversible-reencoding, label-removal, and matched-compute controls with independently implemented evaluation code where feasible.

Output: `FALSIFIED`, `SURVIVES_BOUNDED_FALSIFICATION`, or `REPRODUCTION_FAILURE`.

## G4 — reduction and mathematical extraction

Run the post-signal audit. Try to reduce the mechanism to known mathematics before looking for a novelty story. Extract exact lemmas and asymptotic obligations separately from empirical performance.

Output: known reduction, useful engineering representation, mathematical lemma candidate, or unresolved close prior art.

## G5 — independent mathematical review

Any exact lemma/theorem candidate receives a fixed-commit reviewer who does not trust the writer's conclusion or verifier. Claim-level promotion follows the repository Evidence Policy only.

## G6 — Portfolio decision

Promote to a standalone `CAM-AFRD` only if at least one reusable representation survives G2-G4 **and** the work has enough follow-up breadth for a sustained multi-task programme. Otherwise AFRD stays inside `CAM-AIMATH-ND` or closes as a bounded negative experiment.
